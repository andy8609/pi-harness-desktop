## 7. 结论

- 核心链路（配置 → 连接 → 工具发现 → 调用 → 状态/错误）**功能等价**，并有两项增强（工具级开关、stdio 授权确认）。
- 差异集中在**生态功能**（第三方配置导入、自定义市场来源、插件声明 MCP）与**完整 OAuth**，均在 `design-decisions.md#D13`、`market-design.md#D13` 中作为明确取舍，无隐性缺失。
